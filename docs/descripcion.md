# Descripción del proyecto

Organizador Personal es una aplicación pensada para ayudar a las personas a llevar el control de sus tareas y notas diarias. La idea es ofrecer un lugar sencillo donde se puedan registrar pendientes, darles seguimiento y anotar información relevante, evitando depender de papeles sueltos o recordatorios dispersos.

En esta primera etapa el proyecto se limita a definir la estructura base, el entorno de trabajo y las dependencias necesarias para su futuro desarrollo.
